Now · Solexsis Research

Braid, a language model that reads raw bytes

No tokenizer, and not a transformer. Braid is a causal U-Net over the byte stream: it does most of its work with cheap convolutions and only attends inside two bounded windows. The background of this page is a braid too, which is not a coincidence.

Parameters
295M
Vocabulary
256 bytes
Context
8,192 bytes
Decode state
2.44 MB, flat

Against a matched transformer

  • 3.07× training throughput
  • 2.23× less peak memory
  • 2.99× less energy

At equal data the transformer still finishes 0.019 bits per byte better. The win is time, memory and energy, not quality.

~30M params each, same FineWeb bytes, one RTX 3090, three seeds.
